Поиск по документам

  • Поиск идёт по тексту документов с учётом словоформ: по запросу «кот» найдутся и «кота», и «коты».
  • Показываются до 20 самых подходящих документов, отсортированных по дате создания — сначала новые.
  • Документ можно удалить — он исчезнет и из базы, и из поискового индекса.
